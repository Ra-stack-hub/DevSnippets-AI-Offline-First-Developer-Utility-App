# DevSnippets AI

**Offline-First Developer Utility App**

DevSnippets AI is a powerful, offline-first application designed for developers to manage, store, and interact with code snippets directly on their device. Built with React Native and Expo, it features seamless AI integration and a premium user interface.

## 🚀 Features

- **Offline-First Storage**: Powered by SQLite for reliable on-device snippet management.
- **Smart AI Integration**: Analyze code, generate explanations, or optimize your snippets using local/cloud AI services.
- **Syntax Highlighting**: Beautiful code rendering supporting multiple programming languages.
- **Folder & File Management**: Organize your snippets seamlessly.
- **Favorites & Bookmarks**: Quickly access your most used code blocks.
- **Dark Mode & Premium UI**: Built with NativeWind (Tailwind CSS) for a stunning, responsive aesthetic.

## 🛠 Tech Stack

- **Framework**: React Native (Expo)
- **Styling**: NativeWind (TailwindCSS)
- **Navigation**: React Navigation (Bottom Tabs & Native Stack)
- **Database**: Expo SQLite
- **Icons**: Lucide React Native

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Ra-stack-hub/DevSnippets-AI-Offline-First-Developer-Utility-App.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the app:
   ```bash
   npx expo start
   ```
   Press `a` to run on Android, `i` to run on iOS, or scan the QR code using the Expo Go app.
